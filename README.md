# 🛰️ SafeRoute — Intelligent Disaster Navigation System

**SafeRoute** is a Flutter-based mobile application designed to help users navigate safely during disasters like floods, landslides, or earthquakes.  
It combines **real-time location tracking**, **machine learning**, and **smart routing algorithms** to suggest the safest and most efficient routes while avoiding hazardous zones.

---

## 🚀 Features

- 📍 **Real-time GPS Tracking** — Uses high-precision GPS to show your live location on the map.  
- ⚠️ **Dynamic Hazard Detection** — Detects and marks danger zones using ML-based predictions and live data.  
- 🧭 **Smart Route Guidance** — Calculates safe paths that bypass blocked or hazardous areas.  
- 🌐 **Offline Map Support (Coming Soon)** — Access maps and safety data even without an internet connection.  
- 🧠 **AI-Powered Prediction** — Uses time-series models to predict risk levels based on historical disaster patterns.  
- 🔊 **Voice Alerts & Notifications** — Warns users in real-time about upcoming danger zones.
